# Introduction to European Options & Black-Scholes

This repository contains a set of Jupyter notebooks that introduce European option pricing using the Black-Scholes framework. 
These notebooks are part of my learning process and aim to build my intuition as well as technical understanding of financial derivatives.

## Objectives

The goal of these notebooks is to:
- Understand the fundamentals of European call and put options
- Derive and implement the Black-Scholes pricing formula
- Compute and interpret the Greeks (Delta, Gamma, Vega, etc.)
- Visualize option prices and sensitivities
- Gain intuition about hedging strategies

## Content

The repository is structured as follows:

### 1. Pricing a European Call Option Using the Black-Scholes Model
- Implementation of the Black-Scholes formula
- Pricing of European call option
- Visualization of the PnL of European call option

### 2. Option Strategies
- Plots of Bearish strategies
- Plots of Bullish strategies
- Plots of Non-directional strategies

### 3. European option Greeks
- Computation of Delta, Gamma, Vega and Theta
- Visualization of how Greeks evolve with the underlying asset price

### 4. Butterfly Strategies
- Long Butterfly Spreads
- Short Butterfly Spreads

### 5. Strangle and Delta Hedging
- Simulation of a hedging strategy
- Construction of a delta-neutral portfolio
- Comparison between hedged and unhedged positions
